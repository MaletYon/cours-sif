# Livret de correction : accès réservé

Le livret de correction du cours SIF (`SIF_correction.pdf`) réunit :
- les corrigés expliqués des exercices de chaque chapitre ;
- la correction des fiches d'exercices de NDAP SUKULU.

Il est réservé aux enseignants et aux étudiants qui ont rendu leur travail. Il n'est donc pas publié dans ce dépôt public.

**Pour l'obtenir, écrivez à l'enseignant : maletyon@proton.me.** Précisez votre nom, votre établissement et l'usage prévu.
